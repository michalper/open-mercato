# Screenshots — `@open-mercato/marketing-automation`

Images referenced from pull request #6749. An orphan branch carrying nothing but these files: a PR body needs
somewhere to point, and putting them on the code branch would mean a reviewer downloads 4 MB of PNG to read a
diff.

Taken against a running dev instance at 1920×1200 on a 2× display, cropped 170px from the bottom — the dev
runtime anchors a "Demo Environment" notice there, outside the document a script can reach.

Retaken after a UX audit, a code review and a security review of the branch. Visible differences from the
first set: the runs list names customers instead of printing uuid prefixes, triggers read as sentences rather
than event ids, the funnel is drawn as a funnel, the journey preview takes a customer by name, and three error
messages that were rendering in body colour now use the status token they meant to.
